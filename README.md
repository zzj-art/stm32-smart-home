# 多源感知智能家居环境监测与无线联动系统（STM32F407）

> 课程设计 / 个人项目 · 2026.04 – 2026.06
> 主控：STM32F407ZET6（GEC-M4 开发板）· 工具：STM32CubeMX + Keil MDK 5.14 · HAL 库

## 一句话

用一块 F407 采集温度/湿度/可燃气体/光照/人体五类信号，本地 OLED 显示与按键翻页，掉电可存参数，
并通过蓝牙（HC-05）和 Wi-Fi（ESP8266）对外提供状态查询与远程配置。

## 硬件与接口

| 模块           | 接口              | 说明                                   |
| -------------- | ----------------- | -------------------------------------- |
| DHT11 温湿度   | 单总线 GPIO       | 起始信号 ≥18 ms，40 bit 数据           |
| MQ-7 一氧化碳  | ADC1_IN8（PB0）   | 连采 10 次去掉最大最小，取 8 次平均    |
| 光敏电阻       | ADC               | 12 位，约 0.8 mV/LSB                   |
| HC-SR501 人体  | GPIO 数字量       | 边沿触发，软件消抖                     |
| SSD1306 OLED   | I2C1（PB8/PB9）   | 128×64，页寻址；地址 0x3C              |
| AT24C02 EEPROM | I2C1 同总线       | 256 B，页写 8 B + 5 ms 等待；地址 0x50 |
| HC-05 蓝牙     | USART2（PA2/PA3） | 9600 8N1                               |
| ESP8266 Wi-Fi  | USART3            | AT 指令状态机                          |
| 蜂鸣器         | TIM13 PWM         | PSC=41, ARR=999 → 2 kHz                |

## 软件结构

```
BSP/        板级驱动（GPIO、I2C、USART、ADC、定时器）
HARDWARE/   器件驱动（DHT11、MQ-7、SSD1306、AT24C02、ESP8266）
APP/        业务逻辑（采集、显示、按键、联动、通信协议）
```

主循环是**时间片轮询**：20 ms 处理按键与显示，1 s 处理采集与上报，没有用 RTOS。

## 通信协议（自定义文本指令）

`Q` 查询全部状态 · `T:30` 设温度阈值 · `S:500` 设采样周期 · `L:100` 设光照阈值 · `R1:1` 设继电器

## 踩过的坑（真实记录）

1. **HAL_Delay 卡死**：工程里 `delay.c` 的 SysTick 中断没调用 `HAL_IncTick()`，导致 `HAL_Delay` 永远等不到。
2. **串口 ORE 溢出**：接收中断里没读 DR 就清标志 → 之后再也进不了中断，加了重挂接收。
3. **I2C 双器件共存**：OLED 与 EEPROM 同总线，页写等待不足会互相拖死。
4. **烧录不生效**：只按了 Build 没按 Download，芯片里跑的是旧固件（后来靠产物时间戳判断）。
